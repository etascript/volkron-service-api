# Kellu

Kellu es una aplicacion web para gestionar solicitudes comerciales recibidas desde formularios publicos. Esta pensada para negocios que necesitan ordenar cotizaciones, pedidos, reservas o contactos sin depender de planillas dispersas ni procesos manuales dificiles de seguir.

El sistema centraliza cada solicitud en un panel administrativo privado, donde el equipo puede revisar los datos del cliente, cambiar estados, agregar seguimiento, filtrar registros y exportar informacion para analisis o gestion interna.

## Que problema resuelve

Muchos negocios reciben solicitudes desde formularios web, WhatsApp, correos o campanas en redes sociales, pero luego pierden visibilidad sobre el estado de cada caso. Kellu ayuda a transformar esas solicitudes en un flujo operativo claro, trazable y facil de administrar.

## Principales bondades

- Centraliza solicitudes en un panel privado.
- Permite crear registros desde formularios publicos o manualmente desde el admin.
- Mantiene historial de cambios y seguimiento por solicitud.
- Incluye estados configurables segun el negocio.
- Permite buscar, filtrar y exportar datos.
- Entrega estadisticas simples para entender volumen, servicios mas solicitados y evolucion de contactos.
- Usa eliminacion logica para no perder informacion por error.
- Incorpora login y recuperacion de contrasena.
- Esta disenado con enfoque mobile first.
- Puede instalarse en servidor propio mediante Docker.

## Para quien es

Kellu sirve para pequenas y medianas empresas que reciben solicitudes comerciales y necesitan una herramienta simple para gestionarlas. Puede adaptarse a rubros como servicios tecnicos, construccion, energia, mantencion, asesorias, reservas, pedidos personalizados o captacion de prospectos.

## Valor del producto

Kellu permite pasar de un formulario aislado a un sistema de gestion operativo. En vez de recibir datos y perderles seguimiento, el negocio obtiene una bandeja centralizada donde cada solicitud tiene estado, detalle, historial y contexto.

Su enfoque liviano permite implementarlo rapidamente, mantener control de los datos y adaptar el flujo segun las necesidades de cada cliente.
